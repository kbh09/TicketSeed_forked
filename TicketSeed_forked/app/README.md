## db.py

### 목적

- SQL 데이터베이스를 불러오기 위한 기능(함수) 구현

### 로직

| 함수                      | 설명                                                                     | parameter                                                                                   | return               |
| ------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- | -------------------- |
| `query(sql, params=())` | 데이터베이스의 여러 행의 값을 가져오는 기능                              | `sql` = SQL 구문 `string`<br />`params` = SQL 구문의 ? 값에 할당할 칼럼명 `string` | `List(Tuple)`      |
| `one(sql, params=())`   | 데이터베이스의 한 행의 값을 가져오는 기능                                | `sql` = SQL 구문<br />`string` = SQL 구문의 ? 값에 할당할 칼럼명 `string`            | `Tuple`            |
| `dicts(sql, params=())` | 데이터베이스의 여러 행의 값을 가져와서 데이터프레임 형식으로 만드는 기능 | `sql` = SQL 구문<br />`string` = SQL 구문의 ? 값에 할당할 칼럼명 `string`            | `List(Dictionary)` |
